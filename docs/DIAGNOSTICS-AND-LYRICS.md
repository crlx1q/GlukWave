# Общий журнал ошибок и тексты LRCLIB

Все клиенты используют один сервер. Настройка стороннего API пользователю не нужна.

## Ошибки

Веб собирает необработанные исключения, отклонённые Promise, ошибки React, сети, аудио, WebSocket и загрузки ресурсов. Flutter собирает FlutterError, ошибки основного isolate, API, проигрывателя, комнат и запуска; код общий для Android и Windows. Сервер сохраняет log.error и при необработанном исключении завершает процесс после попытки сохранить запись. Ошибки отдельных дополнительных isolate и аварии ОС/нативной библиотеки вне Dart/JS этим механизмом не гарантируются.

`POST /api/diagnostics/events` принимает до 10 записей за запрос. Клиенты держат ограниченную очередь в памяти, объединяют частые повторы и повторяют отправку с задержкой при недоступности сети. Заголовки авторизации, тела форм и запросов не включаются; известные секреты, адреса почты, параметры URL, строки подключения и личные пути очищаются и на клиенте, и повторно на сервере. Очередь очищается при смене аккаунта/сервера и не записывается на диск. После закрытия приложения неотправленные события могут потеряться.

Журнал доступен только администратору: фильтры платформы/статуса, поиск, последние примеры, количество повторов, время первого/последнего события, статусы «открыто / исправлено / игнорировать». Новое повторение исправленной ошибки открывает её снова. Клиент не может выдать запись за серверную или подставить ID другого пользователя. Число групп ограничено 1000, хранение — 30 дней, отправка ограничена по частоте. SQLite/MongoDB используют то же хранилище, что основной сервер.

## Текст песни

Сервер обращается к [LRCLIB](https://lrclib.net/docs) по названию, исполнителю, альбому и длительности. Автоподбор проверяет совпадение метаданных и не заменяет ручной текст. Положительный кеш — сутки, отсутствие результата — час; при ошибке внешнего сервиса действует короткая пауза. Одинаковые параллельные запросы объединяются, время и размер ответа ограничены. Таймкоды LRC преобразуются в секунды; строка подсвечивается по позиции плеера.

Редактор веба и Flutter позволяет уточнить название/исполнителя, найти варианты, выбрать текст с таймингом либо обычный и поправить его перед сохранением. Для внешнего трека правки личные; для локального файла редактирование разрешено владельцу/администратору. Источник возвращается как LRCLIB. Инструментальные записи могут не содержать текста; каталог LRCLIB не покрывает каждый трек.

## Проверки 8 октября

В изолированной базе проверены права доступа, очистка секретов, три платформы, параллельные повторы и повторное открытие исправленной ошибки. Настоящий браузер отправил ErrorEvent и закрыл запись через админку. Живой HTTP-запрос сервера получил 39 строк с таймкодами; редактор выполнил настоящий поиск LRCLIB и импорт выбранного результата. Flutter проверил реальную отправку HTTP и выбор/сохранение текста в редакторе при ширине 320 и 1280. Физический телефон этим проходом не проверен.
