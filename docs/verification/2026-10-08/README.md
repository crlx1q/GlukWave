# Подтверждения сборки 8 октября

`evidence.json` содержит результаты текущей проверки сервера, настоящего Atlas/R2, веба/PWA, шести языков, APK, статических шрифтов и скачивания. Это сохранённые результаты, а не результаты автоматического запуска после распаковки архива. `native-source-freeze.json` позволяет пересчитать SHA-256 всех 62 исходников/ресурсов, из которых собран отдельный APK.

Низкоуровневые журналы и изображения остаются в `work/qa` рабочего проекта. В архив не входят рабочая база, аккаунты, токены, письма, `.env`, тестовое аудио или ранее собранные APK. Актуальные пределы проверки описаны в `outputs/VERIFICATION.md`.

Прежняя единичная пауза SoundCloud не получила установленной причины; последующие записанные проверки сохранили тот же официальный плеер без PAUSE. Android проверен компиляцией и widget-тестами, аппаратный запуск не подтверждён. Windows/iOS не собраны, публичный домен не развёрнут.
