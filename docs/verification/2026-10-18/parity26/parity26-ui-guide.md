## Evidence boundaries and outstanding review

- The exact intermittent `_InactiveElements.remove`2115 cold-open assertion was not reproduced. The tested fix addresses the observed restoration-order risk and stable root/form lifecycle. Device-level cold launches and final packaging are root's separate verification.
- The **extra** augmented web lyric script `parity26-lyrics-toast-browser.mjs` did not establish the requested local/canonical cue transition in the silent-media fixture: independent playback ignored some fixture remote samples. Its failure log is preserved, and it is not counted as PASS. Native actual PlayerPage media-sample transition is measured PASS. Initial browser lyrics screenshot verifies focus treatment, not that extra transition. All physical clock/timeline helper files from25 were left untouched.
- Stable web runs reported Vite ResizeObserver loop warnings during viewport changes. No RenderBoundary failure occurred in the clean final fixture. Earlier live-HMR runs did produce “Missing store” while root changed store/player modules; HMR was then disabled for isolated inspection. Neither warning is hidden or suppressed.
- Full native regression exposed a genuine fullscreen hit-routing issue: `MouseRegion(opaque:false)` populated the physical face's child hit path but returned false to the ancestor queue recognizer. Setting `opaque:true` while retaining `deferToChild` preserves physical-only clipping and lets that recognizer receive actual face hits. The regression now explicitly requires the visible sleeve center in the queue hit path and an empty stage corner outside it, then performs the same bounded-next swipe at320/390/768/1280. No cover geometry or clock algorithm changed.
- Final phone settings label was corrected from repeated heading “В твоём ритме” to “Раздел настроек”. The broad suite also exposed narrow large-text dropdown intrinsic-width overflow; auth/category pickers now use `isExpanded:true` and bounded option text. Older category-navigation tests now tap the actual adaptive dropdown; the active appearance-dialog language assertion is scoped to that picker. Compact EQ tests open the real full-player control and retain their DSP/curve assertions. The loading-vector fixture asserts its900ms cycle; playing1200ms behavior remains separately tested. Final full-suite verification remains root-owned.
