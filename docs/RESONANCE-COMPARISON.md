Liner изучен как референс с прямого разрешения владельца. Полезные механизмы: отдельная поднятая карточка/точка захвата/место вставки/автопрокрутка, явные состояния обновления, ограниченный кеш запросов и локальные монотонные часы. Его серверный API не переносится вместе с открытым клиентом. В27 собственные существующие движки GlukWave усилены этими общими подходами; новые возможности должны пройти отдельные проверки до выдачи сборки.
