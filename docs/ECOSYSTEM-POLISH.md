## Что осталось вне локальной проверки

Физические устройства и production владелец проверяет самостоятельно. Текущая работа не подтверждает отсутствие длительной утечки памяти на хостинге. Измерения RSS, heap, задержки цикла событий и, при наличии cgroup, общей памяти контейнера доступны в админке. Обновление кода на хостинге и применение ограничения ещё не выполнены.

SQLite уже поддерживается проектом. Для будущего переключения необходимо согласовать `DB_DRIVER=sqlite`, путь `DATA_DIR` и перенос данных; одного удаления URI недостаточно, если `DB_DRIVER` останется `mongo`. Сейчас действующие настройки и данные не менялись.

Профиль в `compose.yaml` ограничивает контейнер вместе с дочерними Python/FFmpeg-процессами; heap Node имеет отдельный потолок 2048 МиБ. Эти параметры опираются на [официальный справочник Docker Compose](https://docs.docker.com/reference/compose-file/services/). Админка читает фактические ограничения cgroup; на обычном Windows-запуске подготовленный лимит не выдаётся за применённый.

Готовые APK/EXE определяются `outputs/releases.json`. Изменение исходников само по себе не обновляет эти файлы. Новая упаковка выполняется только после окончательной проверки исходников.
