# Connect и клиенты 1.0.0+4 — 9 октября 2026

Это завершённая итерация проекта, а не заявление о готовности всей платформы. Общая очередь задач остаётся в [ROADMAP.md](ROADMAP.md).

## Что изменилось

- Один постоянный ID установки и отдельный ID вкладки/запуска. Повторный вход не размножает аппараты; звук принадлежит одному выбранному выходу, остальные клиенты показывают его трек, очередь и время. Раздельное прослушивание изначально выключено.
- Перенос требует подтверждения реального воспроизведения. Ошибка возвращает управление исходному выходу. Закрытие играющей вкладки останавливает её состояние, даже если соседняя вкладка остаётся онлайн. Закрытая вкладка не подменяется другой при адресной команде.
- Отключение устройства отзывает связанные сессии. Free — 3 устройства, Beta/Unbound — 10; конкурентная регистрация сверх лимита удаляет самое старое. Старые записи мигрируют при подключении.
- Комнаты имеют public/private режим, пятизначное приглашение, каталог публичных комнат в вебе, закреплённое участие и присутствие. Сервер ограничивает Free одной комнатой и 10 участниками своей комнаты, расширенные планы — 10 комнатами и 30 участниками. В Flutter создание публичной/приватной комнаты готово; каталог других публичных комнат ещё требуется.
- Исправлен русский публичный поиск SoundCloud. Проверены реальные запросы «кино» и «Мои глаза сияют». Нормализованный Unicode проходит через публичный интерфейс сайта; результаты дополнительно проверяются по публичным страницам треков. Произвольные URL и приватные записи не принимаются.
- Веб-плеер сохраняет обложку и управление рядом с текстом/комментариями. Работают кликабельные таймкоды, в том числе на удалённом выходе и у восстановленного плеера на паузе. Перемотка не включает музыку сама. Громкость сохраняется после reload; колесо над регулятором меняет громкость без прокрутки страницы.
- Flutter получил отдельную компоновку ПК с боковой панелью прослушивания и компактную мобильную. Официальные видимые плееры SoundCloud/YouTube размещены внутри постоянного host; переход по страницам не уничтожает host. Spotify/Яндекс без разрешённого потока не изображают работающее воспроизведение. Android YouTube остаётся foreground-плеером.
- Удаление/замена аватарки и баннера очищает локальный объект либо R2; неудачная очистка ставится в повторную очередь. Анимированные профильные изображения ограничены расширенными планами. Смена пароля проверяет текущий пароль и отзывает остальные сессии. Вход принимает почту или username.

## Проверки

42 серверных теста прошли, дополнительный повтор Connect после изменения сценария конкурентного входа прошёл. Flutter: 101 тест и analyzer без замечаний. TypeScript и production web build прошли. Независимая оценка текущего дизайна: Web PASS, Native PASS по widget-композиции; проверены ПК, планшет и телефон, светлая/тёмная/AMOLED темы.

APK `outputs/GlukWave-android-debug.apk`: версия 1.0.0+4, тестовая подпись, тот же сертификат, что у сохранённой +3. Проверены подпись, manifest, версия, текущий kernel, 11 статических начертаний и совпадение с 96 замороженными файлами исходников. Закрытая резервная копия signing key хранится вне проекта; ключ в архив не входит. Физическое обновление ранее установленного на телефоне APK не проверялось.

Windows `outputs/GlukWave-Setup.exe`: один установщик с необязательными ярлыком рабочего стола и автозапуском. WebView2 bootstrapper Microsoft включён внутрь и ставит runtime при его отсутствии; для этого нужен интернет. Проверены Release/AOT, DLL, шрифты, лицензии, CRC всех файлов portable ZIP и 76 использованных файлов независимой короткой копии. Настоящая тихая установка в отдельную QA-папку установила 72 совпадающих файла; меню Пуск создаётся, невыбранные задачи не выполняются; настоящее удаление очистило QA-регистрацию и ярлык. Обычные интерактивные флажки физически не нажимались. Установщик и приложение не подписаны Authenticode.

При первой проверке параметр `/GROUP` игнорировался из-за отключённой страницы выбора группы. Ярлык установленной версии был восстановлен; её executable сохранил прежний SHA-256. В установщике включена штатная страница группы, повторный тест использовал отдельную группу и сохранил существующие ярлыки и приложение.

API двух локальных серверов отдаёт версии +4 и точные ranges; полное HTTP-скачивание EXE совпало с локальным SHA-256. Машиночитаемые результаты: [verification/2026-10-09/connect-evidence.json](verification/2026-10-09/connect-evidence.json).

## Что остаётся

Друзья и временные джемы, публичные плейлисты/коллажи с собственным cover, новая статистика, расширенная админка, смена почты/удаление аккаунта, оставшиеся тарифные ограничения и проработка профиля Flutter ещё не завершены. Расширенные API Discord для веба/телефона не обещаны; существующий desktop IPC сохраняется.

Физический звук Windows/Android, жизненный цикл WebView, фоновый переход следующего внешнего трека, трей/mini и QR на реальных устройствах требуют отдельной проверки. Widget-тесты не заменяют её. Эти пункты остаются открытыми в плане.

Бинарные клиенты собраны с адресом `https://wave.gluk.tech`. Новые серверные функции проверены локально; сервер и файлы на публичном домене в этой итерации не публиковались. Старое развёртывание не предоставляет новый native CAPTCHA/Connect; клиент сохраняет совместимость с подтверждённым отсутствием Connect. Полноценное использование новой синхронизации требует отдельного обновления серверного развёртывания.
