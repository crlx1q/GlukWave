# GlukWave — состояние проекта и сохранённый объём задач

Проект продолжается в текущих файлах. Веб — React, сервер — Node.js, Windows/Android/iOS — Flutter в `apps/native`. Внешние платформы подключает владелец сервера, пользователь не вводит API-ключи.

## Макеты и правки

- `Gluk-Wave-v2.html` задаёт исходный стиль и функции: темы/палитры, параметры движения, варианты волны, обложка винил/CD/3D/плоская, Lo-Fi, очередь, тексты. Эти возможности сохраняются.
- Фотографии пользователя задают направления настройки, профиля, комнат и полноэкранного плеера.
- `Gluk-Wave-v6-PC-fixed.html` уточняет мобильный интерфейс: три нижние вкладки, мини-плеер над ними, жесты и растущая обложка, полный экран, скелетоны при настоящей загрузке. Его демонстрационные треки и таймеры воспроизведения в приложение не переносятся.
- Последние конкретные замечания: `h:mm:ss` для длинных треков; форма/расположение активного лайка; SoundCloud не прерывается при переходах; компактный источник; исправленное нижнее меню; волна заполняет весь свой блок; полноценное меню настроек; полный экран трека и мобильные жесты.
- Дополнение 7 октября: основной английский, ru/kk/uk/de/es, автоматический выбор по стране IP/языку устройства и сохранение ручного выбора; отдельный сайт-визитка со скачиванием и переходом в музыкальное приложение.
- Дополнение 8 октября: `index(3).html` и два видео задают новую широкую волну с частицами и реакцией на движение курсора; `Gluk Wave v7.html` уточняет лаконичную мобильную навигацию и жесты; `miyux-ideal-standalone.html` — визуальные приёмы профиля. Запрошены полноценный эквалайзер, настройки, анимации значков, исправления комнат и устройств. Это отдельная текущая итерация, а не подтверждение полной готовности платформы.

## Что уже существует в коде

| Направление | Реализация | Практическая граница |
|---|---|---|
| Хранение | SQLite по умолчанию, MongoDB Atlas; файлы локально либо приватный R2. 8 октября основной сервер работает с настроенными владельцем Atlas/R2 | Реальные регистрация, сохранение, конкурентные изменения, upload/stream/range/download/delete проверены в отдельной временной облачной базе и на собственном WAV; перенос существующей библиотеки отдельно не выполнялся |
| Языки | Шесть локальных каталогов в вебе, сайте и Flutter; выбор до входа, сохранение offline, синхронизация аккаунта, серверная география IPv4/IPv6, переведённые HTTP/Socket сообщения и письма | IP-география приблизительна; музыка и пользовательские тексты не переводятся |
| Сайт/скачивание | Отдельная визитка на `/`, приложение на `/app/`, совместимые старые ссылки и offline-оболочки; сервер выдаёт только зарегистрированные пакеты с проверкой SHA-256/размера | Android debug предназначен для локального тестирования; Windows/iOS до реальной сборки не предлагаются для скачивания |
| Авторизация | Почта/пароль, Google OAuth, QR с подтверждением, защищённые сессии, Turnstile/SMTP в production | В изолированных тестах CAPTCHA/SMTP отключены; живые письма и OAuth владельца отдельно не проверялись; без SMTP восстановление не обещает отправку письма |
| SoundCloud | Настоящий публичный поиск/метаданные без ключей, официальный веб-плеер; OAuth-импорт при серверных ключах | Полноценный собственный аудиопоток отличается от управления widget; во Flutter внешний источник пока открывает площадку |
| Spotify/YouTube | Официальные ссылки/плееры, поиск и импорт при серверных ключах; пагинация библиотеки | Живые аккаунты/квоты/доступ площадок отдельно проверяются владельцем |
| Яндекс Музыка | Импорт реального CSV/JSON и официальный плеер | Прямой вход и закрытый поиск не реализованы |
| Медиатека | Собственные аудиофайлы, плейлисты, избранное, история, комментарии с временем, LRC/обычный текст | LRC внешнего трека сохраняется лично для пользователя; автоматический поиск Genius пока не реализован |
| Кеш | Автокеш по умолчанию, ручные загрузки, размеры и очистка, изоляция сессии/сервера | Offline доступен только при реально предоставленном разрешённом аудиофайле |
| Волна/обложка/Lo-Fi | Измеренная огибающая, варианты волны, курсор/касание; в вебе текущий default Silk заменён на широкую волну с частицами из нового макета, остальные варианты сохранены; варианты обложки; реальные сцены и отдельная атмосфера; мобильное раскрытие и жесты | Новая волна v7 пока относится к вебу; Flutter сохраняет прежний рендер. Внешние плееры и прямое аудио имеют разные возможности; физическое устройство ещё не проверено |
| Эквалайзер веба | Настоящие 10 полос Web Audio, предусиление, пресеты с запасом громкости, ограничитель пиков; сохранение и синхронизация настроек; скорость 0.5–2× | Применяется к аудио GlukWave, включая локальный кеш, а не к звуку стороннего iframe. Скорость в комнате принудительно 1×. Native EQ ещё не добавлен |
| Устройства | Команды, громкость, позиция, перенос с подтверждением/откатом, серверная временная шкала | Локальная сеть требует работающего общего сервера; разные сети — доступного интернет-сервера |
| Комнаты | Приглашения, роли/право управления, чат, синхронизация и доступ к приватному треку на время участия | Нужны проверки физических устройств и продолжительных сетевых сбоев |
| Flutter | Android системный audio_service, Windows медиакоманды, трей, mini/window mode, Discord IPC, локальный кеш | Android-компиляция не равна проверке телефона; Windows C++ инструментарий пока отсутствует; iOS требует macOS |
| Профиль | Реальные аватар/баннер/GIF, имя, описание, теги, бейдж тарифа | Полная социальная система друзей/личных сообщений, тонкая приватность и публичная статистика ещё требуют развития |
| Тарифы | Free/Beta/Unbound, серверные лимиты, Stripe Checkout/Portal и подписанный webhook, админ-план | Реальные платежи/ключи не выполнялись; Beta выдаёт администратор |
| Push/admin | Web Push VAPID, FCM при конфигурации, административные действия/аудит | FCM/APNs, живой Discord и OAuth требуют соответствующих аккаунтов/устройств |

## Оставшиеся условия полного результата

Работа не ограничивается последним макетом: исходные задачи по четырём площадкам, Flutter, локальной сети, аккаунтам, комнатам, устройствам, кешу, профилю, тарифам, push и административной консоли сохраняются. Пока не подтверждены все внешние сценарии, EXE/iOS, фоновые источники, социальные функции и публичный запуск, проект не обозначается завершённым на 100%.

Домен `wave.gluk.tech` задан для будущего production, но не развёрнут. Подготовлены Docker/Caddy и CI; реальная публикация и запуск CI на GitHub ещё не выполнялись. Конкретные свежие тесты и файлы сборок фиксируются в `outputs/VERIFICATION.md` после завершения текущей проверки.
