# GlukWave — план продолжения, 9 октября 2026

Существующий код и исходные HTML сохраняются. Статус «готово» означает реализацию с указанной проверкой, а не наличие кнопки. Работа идёт последовательно по зависимостям; новые задачи добавляются сюда. Общие старые ограничения сохранены в docs/PROJECT-STATUS.md.

## 1. Общее прослушивание и устройства — реализовано, проверка фона остаётся

- [x] Постоянный ID устройства, reload не создаёт новый аппарат; несколько вкладок одного браузера не засоряют список.
- [x] Общий плеер аккаунта по умолчанию: новый клиент сразу показывает трек, очередь, позицию, активный аппарат; управление отправляется туда без второго звука.
- [x] Отдельное прослушивание выключено по умолчанию, явный переключатель; перенос звука с подтверждением и откатом.
- [x] Онлайн/переподключение/offline; отключение аппарата с отзывом сессий, понятный текущий аппарат.
- [x] Free 3 устройства, Beta/Unbound 10; вход сверх лимита отзывает самый старый аппарат. Применить на сервере, проверить конкурентный вход.
- [ ] Исправить переход следующего трека при свёрнутом окне; проверять без зависимости от FullPlayer/render.
- [x] Громкость колесом мыши в поле регулятора; сохранение настройки остаётся.

## 2. Комнаты и друзья

- [x] Закреплённое текущее участие, состояние подключения, устройства участников, видимый выход; комнаты доступны в мобильном вебе.
- [x] Публичные комнаты в каталоге либо приватные; короткий цифровой код 5 знаков и ссылка, ограничение попыток подбора.
- [x] Free: создание/участие до 1 комнаты, вместимость своей комнаты 10; Beta/Unbound: до 10, вместимость 30. Права управления и модерация.
- [ ] Друзья: поиск ника, заявки/принятие/отказ/удаление, приватность активности, онлайн и что слушают.
- [ ] Временный скрытый «второй наушник»/джем до 5 друзей: состояние ведущего, права/локальная пауза слушателя, выход и удаление пустого джема.
- [x] Сетевые тесты reconnect, дублирования ended/seek, доступа к приватным трекам, нескольких вкладок и аппаратов.

## 3. Каталог, тексты и библиотека

- [x] Диагностика и исправление русских запросов/неверной раскладки; проверить настоящий внешний поиск и нормализацию Unicode.
- [ ] Жанры и поиск/переход к артистам; импорт/разбор плейлистов источников. Импорт только Beta/Unbound — реальная серверная проверка.
- [ ] Таймкоды LRCLIB и дополнительные реальные источники, сохранённый текст; без выдуманных таймингов.
- [x] Lyrics справа сохраняют обложку/управление, не перекрывают заголовок; кликабельный таймкод, плавный текущий текст, верные skeletons.
- [ ] Текст под обложкой построчно, комментарии с временем; отдельные настройки видимости обоих.
- [ ] Публичность своих плейлистов, профиль/поиск публичных, права на приватные треки.
- [ ] Коллаж 1–4 обложки, мягкая градиентная обработка; свой cover upload и очистка заменённых файлов R2.

## 4. Аккаунты, тарифы, админка и статистика

- [x] Вход по почте либо имени пользователя с паролем; QR подтверждение с телефона как Guard. Проверить все числовые даты авторизации.
- [ ] Выход, смена пароля с проверкой текущего, смена почты с подтверждением, удаление аккаунта/отзыв сессий.
- [x] Удаление/замена аватарки и баннера удаляет объект локально/R2; никаких потерянных бесхозных фото.
- [ ] Роль справа от ника; профиль с реальными данными, без трёх огромных тарифных блоков. Beta не показывается как покупаемый тариф.
- [ ] Серверные возможности Free/Beta/Unbound: GIF/детальный кастом/импорт/устройства/комнаты; качество аудио зависит от разрешённого источника и реального кодирования.
- [ ] Админка: бан/разбан, просмотр и удаление, контроль регистрации, управление версиями и загрузка проверенных пакетов, аудит.
- [ ] Реальная статистика слушаний, артистов/треков/времени на клиентах и у администратора; защита от дублей, приватность.
- [ ] Discord Rich Presence: сохранить IPC; исследовать разрешённый вариант веб/телефон без открытого десктоп-клиента. Не обещать статус, недоступный официальным API.

## 5. Дизайн и реформа Flutter — основной проход готов

- [x] Flutter ПК: собственная компоновка desktop, плотность/панели/мышь/клавиатура, соответствие качеству веба; Android сохраняет мобильный UX.
- [ ] Официальный внешний плеер внутри приложения вместо редиректа. Реальные команды/позиция/очередь, переживание переходов и мини-режима; ограничения фонового воспроизведения проверить отдельно.
- [ ] Больше готовых тем; доступные шрифт/размер с адаптацией всех экранов, расширенный кастом по тарифу.
- [x] Положение лайка и прямая кнопка настоящего EQ; платформенная обработка звука без фальшивых переключателей.
- [x] Все скроллы в стиле темы; idle sway 3D обложки только при видимости/отсутствии касания, respect reduced motion.
- [x] Футер визитки: большой фоновый GLUK WAVE; темы и доступность сохраняются.
- [x] Свежая независимая оценка и снимки ПК/телефона после реализации.

### Уточнения частично готовых пунктов

- Текст под обложкой и настройки комментариев доработаны в вебе; отдельная унификация с Flutter остаётся открытой.
- Роль и профиль веба переработаны; глубокая реформа профиля Flutter ещё требуется.
- Встроенные источники Flutter реализованы и скомпилированы, но физический звук/фон/трей не подтверждены.
- Device/GIF/room ограничения действуют на сервере; импорт, подробный кастом и качество ещё не закрывают весь запрошенный тариф.
