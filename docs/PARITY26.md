# GlukWave 26 — требования от 16 октября 2026

Готова локальная поставка **1.0.0+26**, 18 октября 2026: Android APK, Windows Release с установщиком и переносным ZIP, собранный web и исходники. Полные проверки и независимая оценка дизайна PASS завершены. Хостинг не обновлялся.

Порядок работы:

1. Устранить нестабильный холодный старт Flutter. Красный экран `_InactiveElements.remove / _elements.contains(element)` появился сразу при открытии приложения и исчез после перезапуска. Не скрывать исключение: исправить порядок восстановления состояния и проверить жизненный цикл ключей/экранов; сохранять очищенный стек для диагностики редкого сбоя.
2. Быстро показывать кеш главной, любимого и плейлистов. Обновлять данные в фоне, сохраняя локальные правки, очередь и экран. Разрыв сети и восстановление не должны требовать перезапуска приложения.
3. Заранее готовить ограниченное число следующих треков/обложек по текущей ленте, с дедупликацией, отменой устаревшей работы, квотой кеша и учётом экономии трафика/энергии. Не скачивать всю библиотеку бесконтрольно.
4. Сопоставить архитектуру поиска Liner с нашей; улучшать измеримые задержки GlukWave. Не обещать скорость чужого сервера на основании интерфейса клиента.
5. Оригинальный общий дизайн входа/регистрации GlukWave, фон из круглых точек/полутонов, экономичная анимация; сохранить доступность, языки и способы входа.
6. Компактный мини-плеер ПК и телефона. На мобильном — полноценный предварительный просмотр при горизонтальном свайпе, возврат при отмене, один переход по завершении; непрерывное раскрытие/сворачивание плеера по жесту и безопасные отступы.
7. Компактные уведомления сверху внутри приложения, с контекстом, закрытием и защитой от повторяющегося спама.
8. Полноценные страницы исполнителей: реальные данные, треки, доступные альбомы/плейлисты и исходная площадка; без выдуманных биографий, галочек и статистики.
9. Строки текста двигаются отдельными мягко оседающими плитками по смене таймкода, без непрерывной «беговой дорожки». Сохранить ручной просмотр, переход по строке, вступление и фокус текущей/соседних строк.
10. Упорядочить настройки: поиск, понятные разделы, адаптация ПК/телефона, сохранение существующих функций и локальной отзывчивости.

Главный собственный референс: `docs/design-reference/Gluk-Wave-v7.html`. Видео и изображения пользователя используются только для изучения и не попадают в архив приложения.

Liner: https://github.com/tryliner/desktop и https://github.com/tryliner/covers изучаются отдельно в `work/reference`. Desktop распространяется по Source-Available & Non-Commercial Contribution License; код, оригинальные ресурсы, фирменный дизайн и внутренние алгоритмы не переносятся в GlukWave. Нужные общие возможности реализуются самостоятельно. Его клиент обращается к официальному Liner API; открытый клиент сам по себе не раскрывает серверный поиск по всем площадкам.

## Что изменилось

Flutter восстанавливает локальный аккаунт, настройки и фонотеку одним согласованным этапом, затем обновляет их в фоне. Кеш метаданных ограничен 48 записями и 2 МиБ, разделён по серверу и аккаунту. Повторные запросы объединяются; ошибки доступа удаляют недействительные записи. Переподключение после потери сети использует интервалы 2/5/10/20/40/60 секунд и проверку при возвращении в приложение, сохраняя декодер и очередь. Очищенный стек редкого сбоя сохраняется для диагностики.

Веб показывает сохранённые любимое и плейлисты до ответа сети, использует IndexedDB и ограниченные запросы. Выход из аккаунта очищает личный кеш и блокирует применение запоздавшего ответа старой сессии. Предзагрузка в обоих клиентах ограничена двумя следующими треками, отменяется при смене очереди и учитывает экономию ресурсов. Если пользователь явно скачал уже подготавливаемый трек, отмена предзагрузки сохраняет его ручную загрузку.

Поиск возвращает быстрые источники, пока остальные ещё работают: первый частичный ответ ждёт не более 1200 мс после запуска провайдеров; отдельный полный ответ использует те же фоновые задания. Это бюджет ожидания провайдеров на сервере, а не обещание времени доставки по интернету. Кеш интерактивного поиска отделён от внутренних запросов рекомендаций и разрешения источника. Профиль исполнителя показывает доступные настоящие треки, альбомы и публичные либо собственные плейлисты, сохраняя исходный поиск при возврате.

Вход получил собственную анимированную сцену из круглых полутонов и устойчивую форму. Мини-плеер стал компактнее: 60 пикселей на телефоне, 68 на ПК, максимальная ширина настольной капсулы 740 пикселей. Горизонтальный жест показывает соседний трек, отмена возвращает исходный, завершение переключает один раз. Вертикальный жест непрерывно раскрывает плеер. Уведомления размещены сверху, строки текста оседают независимо при смене таймкода, настройки получили поиск и адаптивный выбор раздела. Движение фона останавливается при скрытии приложения и ограничивается настройками экономии/уменьшения анимаций.

## Проверки и границы

Полный итоговый набор: Flutter **507/507**, сервер **135/135**, web QA **100/100**, анализатор Flutter без замечаний. Повторные и промежуточные прогоны не прибавляются к этим числам. Реальный браузер дополнительно проверил зависший на 20 секунд сервер, кеш до ответа сети, восстановление с диска, объединение запросов, удаление кеша после 401 и защиту от поздних ответов прежнего аккаунта.

Независимая оценка дизайна: PASS, адаптации 1440/768/375/320, реальные жесты браузера и Flutter-виджетов. Доступен тот же поставщик модели; отдельный поставщик в этой среде недоступен. Видимая грань 3D-обложки принимает свайп, пустые углы сцены пропускают прокрутку.

Исходный редкий `_InactiveElements.remove` при открытии телефона не воспроизведён. Исправлен порядок восстановления и проверены переходы, но это не доказательство устранения именно того единичного сбоя. Физические Android/Windows-аудиоустройства и старый Samsung Tizen не проверялись; запуск legacy-сборки в Chromium с удалёнными API не эмулирует весь старый движок телевизора. Android сохраняет прежний debug-сертификат, Windows без Authenticode; iOS не собирался.

Хостинг, база и установленные приложения автоматически не меняются. Точные файлы поставки 25 сохранены для отката в `outputs/archive/releases/1.0.0+25`. Доказательства — `docs/verification/2026-10-18/parity26/parity26-evidence.json`, контрольные суммы — `outputs/SHA256SUMS.txt`. APK сверён с 230 исходными файлами/ресурсами и прежним сертификатом; Windows ZIP — с фактической Release-сборкой, полным медиадекодером и всеми файлами пакета. Проверены версия установщика, состав и целостность ZIP. Финальная legacy-сборка проверена без внедрения CSS на четырёх размерах, современная капсула сохраняет 740×68 пикселей на ПК и высоту 60 на телефоне.
