# Клиенты 1.0.0+3 — 9 октября 2026

## Реализовано

- Громкость хранится на устройстве: веб localStorage, Flutter SharedPreferences. Нулевое значение сохраняет выключенный звук. Полученные команды громкости также сохраняются.
- Поиск отдаёт артистов отдельно от треков, ищет название, автора, альбом, жанр/теги и слова ранее сохранённых либо полученных текстов доступного каталога. Личные тексты других пользователей не участвуют. Источники с серверными ключами дополняют реальные результаты; неизвестные жанры не выдумываются. Глобальный индекс всех текстов интернета не реализован.
- LRCLIB понимает кредит автора в названии, убирает служебные суффиксы, пробует структурированный поиск. Дополнительный lyrics.ovh возвращает обычный текст. Разница длительности более трёх секунд исключает автоматическое использование таймкодов; при наличии обычного текста используется он. Ручные правки сохраняют приоритет. Покрытие источников ограничено.
- Исправлена числовая дата истечения QR/браузерного входа, вызывавшая `int`/`String` exception. Обе новые сборки задают HTTPS-домен; только прежняя сохранённая настройка `192.168.3.7:4000` автоматически сбрасывается при переходе на домен. Пользовательский иной адрес не изменяется.
- Формы почты/пароля/регистрации внутри Flutter, настоящий Google G, шесть языков, анимация во время реальной загрузки. На новом сервере браузер открывает только Cloudflare-проверку и возвращает одноразовый результат в форму. На старом сервере с CAPTCHA и без новой возможности предлагается явный браузерный вход. Google требует настройки владельцем сервера.
- Телефон подтверждает QR, но сам QR для входа генерируется на ПК/вебе. Windows: одиночный левый клик показывает быстрый плеер, двойной переключает основное окно. Мини-режим без системных кнопок, поверх окон, прозрачность 94%, перетаскивание за заголовок, смена трека колесом/свайпом. Режимы используют одно Flutter-окно, восстанавливают его положение; отдельное одновременное окно быстрого плеера не создаётся.
- Один Windows установщик EXE с библиотеками внутри, установка для текущего пользователя, ярлык и автозапуск отдельными флажками, штатное удаление. Автозапуск по умолчанию выключен, работает с `--start-minimized`.

## Проверено

39 серверных тестов, 87 Flutter-тестов, чистый analyzer, production-сборка веба. В выключенном по звуку браузере: громкость после reload, сохранение mute, настоящий результат артиста, поиск по сохранённому LRC. Независимая оценка оформления входа/плееров: PASS. 91 файл Flutter заморожен и сверён с APK и физической копией Windows-сборки; 11 локальных начертаний проверены.

Установщик действительно установился в отдельную QA-папку, все 66 файлов совпали с Release-набором. При снятых задачах не создан автозапуск/ярлык рабочего стола; меню Пуск создано. Штатное удаление очистило временную регистрацию и ярлык. Реальная выдача EXE сервером сверена по SHA-256. Старое работающее приложение не закрывалось: новый набор находится в `outputs/GlukWave-windows-1.0.0+3`.

## Оставшиеся проверки

Физический телефон, клики по настоящему трею, вывод звука и интерактивный мастер не автоматизированы. APK подписан debug-ключом для beta; Windows не подписан Authenticode. iOS не собран. На `wave.gluk.tech` работает прежний сервер, обновление туда в этой итерации не выполнено; новые API и серверные улучшения доступны локально до публикации обновлённого backend. Полный исходный объём проекта остаётся в `PROJECT-STATUS.md`.
