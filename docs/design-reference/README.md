# Пользовательские макеты GlukWave

Здесь сохранены неизменённые копии двух предоставленных HTML-макетов, чтобы они оставались доступными в архиве исходников. Приложения используют их как ориентир оформления и поведения; эти файлы не подключаются к рабочему вебу или Flutter.

- `Gluk-Wave-v2.html`: исходное оформление и набор настроек, палитры, волны, обложки, Lo-Fi и музыкальные экраны.
- `Gluk-Wave-v6-PC-fixed.html`: уточнение мобильной навигации, мини-плеера, жестов и раскрытия обложки.

Демонстрационные треки, счётчики, искусственные задержки и таймеры макетов не являются данными сервиса. У нового пользователя библиотека пустая; рабочее приложение получает музыку, состояние и результаты загрузки от настоящего сервера/источника.
