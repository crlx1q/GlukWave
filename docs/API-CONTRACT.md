# GlukWave HTTP and realtime contract

Same-origin web uses HttpOnly `gw_session`; native uses `Authorization: Bearer <token>` from login/registration with `X-GlukWave-Client: native`. All errors: `{error:{code,message,details?}}`. Dates ISO, IDs strings, positions/durations seconds. No fixture library, fake users, fabricated comments or fake provider connection state.

## Types
User: `{id,email,username,displayName,avatarUrl?,bannerUrl?,bio,tags:[],plan:'free'|'beta'|'unbound',role:'user'|'admin',emailVerified,createdAt}`.
Track: `{id,title,artist,album,artwork,duration,source:'local'|'youtube'|'spotify'|'soundcloud'|'yandex',sourceId,sourceUrl,playback:{kind:'audio'|'youtube'|'spotify'|'soundcloud'|'yandex',url?,embedUrl?,offline:boolean},createdAt,liked?:boolean}`. Private local tracks are visible to their owner (room membership grants streaming while member). SoundCloud OAuth metadata marked `sharing:private` is stored under an account-specific ID/owner and never enters anonymous catalog/search. Unscoped provider persistence omits private records; importing into another authorized account creates its own ID.
Playlist: `{id,name,description,artwork,trackIds:[],ownerId,createdAt,updatedAt}`.
Settings: `{autoCache:true,cacheLimitMB:1024,lyrics:true,discordPresence:true,notifications:false,language:'auto'|'en'|'ru'|'kk'|'uk'|'de'|'es',theme:'light'|'dark'|'system',reducedMotion:false,revision?:number,appearance:{light:{bg,surface,ink,accent},dark:{bg,surface,ink,accent},radius:24,speed:1,compact:false,blur:true,waveStyle:'silk'|'particles'|'bloom',cover3d:true,coverKind:'vinyl'|'cd'}}`. Language defaults to auto; English is the fallback. Colors are six-digit hex; radius8..38, animation speed0.3..2. PATCH merges both appearance and each palette, preserving other fields. Guest/offline appearance is stored locally by clients and synchronized for the account. Revision is assigned by the server and cannot be supplied in PATCH. Clients retain pending sparse changes across offline restarts; an older response must not replace a newer socket revision or a later local edit.

## Locale and public downloads

- GET `/api/locale` -> `{language,country,source,supported:[{code,name,nativeName}],defaultLanguage:'en'}`. Supported: en/ru/kk/uk/de/es. Source: ip/browser/default. Country is ISO or null; visitor IP is not returned. Local country-only IPv4/IPv6 lookup selects supported regional languages, then weighted `Accept-Language`, then English. Private/LAN addresses have no country. `CF-IPCountry` is not trusted; forwarded IPs follow configured Express proxy trust. Responses are private/no-store and vary by Accept-Language.
- GET `/api/config` includes `localization` with the same automatic result. It does not write a chosen account language. Clients fence automatic responses against explicit local/account selections.
- Clients send resolved `Accept-Language` on API requests. HTTP `error.code` stays stable; human error messages and account emails use the chosen language. Track titles, lyrics, comments, room names and other user data are never translated by the server.
- `PATCH /api/settings` accepts optional `X-GlukWave-Account` with the expected authenticated user ID. A mismatch returns409 `SESSION_CHANGED` before writing. Clients use this to fence delayed settings writes against a cookie/account switch in another tab; it does not grant access or replace authentication.
- Synthetic liked/imported list labels use the requesting language. Once created, a playlist name is stored as user data and is not renamed on a later language switch. Room-join notifications translate only their system phrase, keeping the room title and participant name. In automatic mode, realtime notifications use the receiving socket's locale; push subscriptions store their resolved language. A saved manual account language takes precedence for all receiving devices.
- Socket authentication optionally includes `language` as a resolved supported code. `locale:change` with `{language}` -> ack `{ok:true,language}` updates only this socket's error messages without reconnecting or interrupting playback. Existing session authentication and event-rate limits apply.
- GET `/api/releases` -> `{releases:[{platform,version,channel,bytes,sha256,builtAt,url,available:true,signature}]}`. Only actual allowlisted packages whose size/SHA-256 match `RELEASES_DIR/releases.json` are listed. Missing packages are omitted; an empty list is legitimate. Internal filesystem paths are not exposed.
- GET `/api/downloads/:platform` downloads the verified package, supports byte ranges, sends `X-Content-SHA256`; absent/modified/unrecognised packages return404. Platforms: android (.apk), windows (.zip), ios (.ipa). No nonexistent Windows/iOS artifact is advertised.
- The owner registers a verified built package via `node scripts/register-release.mjs android GlukWave-android-debug.apk 1.0.0 debug`; registration records hash/size/time, it does not compile or prove a build. APK source/kernel/manifest checks happen before registration.
State: `{trackId:null|string,position:0,playing:false,volume:0.8,queue:[],updatedAt:number,revision:number}`.

## HTTP endpoints (all JSON unless specified)
- GET `/api/health` -> `{status:'ok',storage,version}`; GET `/api/config` -> `{appName,appUrl,environment,providers:[{id,name,configured,searchAvailable?,capabilities,reason?}],auth:{google,turnstileSiteKey},push:{enabled,vapidPublicKey},plans:[]}`. SoundCloud public HTML search can be available with `configured:false` (no OAuth credentials). Missing keys do not disable public track links or the official widget. Public integration reasons describe user actions; setup diagnostics are returned only by authenticated `/api/admin/overview`.
- GET `/api/auth/me` -> `{user:null|User}`; POST `/api/auth/register` `{email,password,username,displayName?,captchaToken?}` -> `{user,token?}`. POST `/api/auth/login` `{email,password,captchaToken?}` -> `{user,token?}`. POST `/api/auth/logout`. GET `/api/auth/google/start` browser redirect. POST `/api/auth/forgot` `{email,captchaToken?}` (503 `MAIL_UNAVAILABLE` if SMTP unavailable outside isolated test mode); POST `/api/auth/reset` `{token,password}`; GET `/api/auth/verify?token=...`.
- POST `/api/auth/qr` `{deviceName?}` -> `{id,secret,url,expiresAt}`. GET `/api/auth/qr/:id?secret=...` -> `{status:'pending'|'approved'|'expired',user?,token?}` (approved sets cookie and consumes). GET `/api/auth/qr/:id/info` -> `{deviceName,expiresAt,status}`. POST `/api/auth/qr/:id/approve` authenticated `{}`. Web reads `?qr=ID`, shows confirmation for logged-in user (never approves automatically).
- GET `/api/tracks` -> `{tracks:[]}`. GET `/api/search?q=...&source=all|local|youtube|spotify|soundcloud|yandex` -> `{tracks:[],suggestion:null|string,providers:[],errors:[]}`. Each provider result has persisted track ID. POST `/api/tracks/resolve` `{url}` -> `{track}`. POST `/api/tracks/upload` multipart `file`, `title?`, `artist?`, `album?` -> `{track}`. GET `/api/tracks/:id` -> `{track}`. DELETE `/api/tracks/:id` owner/admin. GET `/api/media/:id` native audio with byte-range support. GET `/api/media/:id/download` only offline-capable tracks. GET `/api/tracks/:id/playback` -> `{playback}` (signed/refreshed stream URLs). External official embeds visible with provider controls.
- GET `/api/library` -> `{tracks,likedIds,playlists,history}`; PUT `/api/library/likes/:trackId` `{liked:boolean}`. GET `/api/playlists` -> `{playlists}`. POST `/api/playlists` `{name,description?,trackIds?:[]}` -> `{playlist}`. PATCH `/api/playlists/:id` `{name?,description?,trackIds?}`. DELETE `/api/playlists/:id`. POST `/api/history` `{trackId,position?}`.
- GET `/api/settings` -> `{settings}`; PATCH `/api/settings` `{...partial}` -> `{settings}`. For example `{appearance:{dark:{accent:'#7ca8bb'}}}` changes only the dark accent. Invalid colors, unknown fields and out-of-range geometry are rejected.
- GET `/api/profile/:id` -> `{user,playlists}`. PATCH `/api/profile` `{displayName?,username?,bio?,tags?}` -> `{user}`. POST `/api/profile/media` multipart `file`, `kind=avatar|banner` -> `{user}`. GET `/api/profile-assets/:id` public uploaded profile image. Upload supports GIF for animated avatar/banner, with bounds.
- GET `/api/integrations` -> `{connections:[{provider,connected,displayName?,configured,reason?}]}`. GET `/api/integrations/:provider/connect` redirect OAuth for spotify/youtube/soundcloud/discord, config missing gives honest error. DELETE `/api/integrations/:provider`. GET `/api/integrations/:provider/playlists` -> `{playlists:[{id,name,description,artwork,trackCount}],liked?:{id,name,trackCount}}`. GET `/api/integrations/:provider/playlists/:id/tracks` -> `{tracks,nextCursor?}`. POST `/api/integrations/:provider/import` `{playlistId,name?,trackIds?}` -> `{playlist,imported}` (imports all pages server-side unless chosen IDs). POST `/api/integrations/import-file` multipart file CSV/JSON (actual exported metadata, include provider source links) -> `{playlist,imported}`. Yandex uses public album/track embed and exported playlist metadata until an approved API is configured; never labels an unofficial OAuth endpoint as available.
- GET `/api/rooms` -> `{rooms:[]}`. POST `/api/rooms` `{name}` -> `{room,inviteUrl}`. Room: `{id,name,ownerId,members:[{userId,displayName,avatarUrl,canControl,role}],state:State,createdAt,inviteCode}`. POST `/api/rooms/join` `{inviteCode}` -> `{room}`. GET `/api/rooms/:id` -> `{room}` members only. POST `/api/rooms/:id/leave`. PATCH `/api/rooms/:id/members/:userId` `{canControl,role?:'member'|'moderator'}` owner only. DELETE `/api/rooms/:id` owner. GET `/api/rooms/:id/messages` -> `{messages:[{id,userId,displayName,text,createdAt}]}`. POST same `{text}`.
- GET `/api/tracks/:id/comments` -> `{comments:[{id,userId,displayName,avatarUrl,text,position,createdAt}]}`. POST same `{text,position?}`. DELETE `/api/comments/:id` author/admin. GET `/api/tracks/:id/lyrics` -> `{lines:[{time,text}],synchronized,source}`; PUT same `{text}` accepts LRC and plain text. Standard `[80:00.00]` and explicit hour format `[1:20:00]` both represent4800seconds; fractions use a decimal point. Invalid seconds or hour-format minutes cannot create synchronized positions. Clients export standard minutes:seconds.fraction LRC separately from the displayed clock. Uploaded local tracks require their owner/admin; external-track edits are personal to the authenticated user and cannot replace another user's text. Empty lyrics remain empty until real text is imported.
- GET `/api/tracks/:id/waveform` -> `{available:boolean,duration:number,samples:number[],source:'decoded-pcm'|'soundcloud-envelope'|null}`. Requires the same track access as playback, including a second check after analysis. Samples are measured mono RMS for protected local/R2 audio, or the official public SoundCloud envelope, evenly spaced across duration. At most4096 normalized samples; unavailable audio returns an empty array. Decode concurrency2, queue20, PCM output128MiB, timeout30s; SoundCloud fetch permits only `wave.sndcdn.com`,256KiB JSON and no redirects. Private responses use `Cache-Control:private,no-store`. Server cache is reproducible metadata and expires after7days (60s for failure); clients may retain envelopes alongside their own offline audio.
- GET `/api/devices` -> `{devices:[{id,name,kind,online,lastSeen,state}]}`. POST `/api/devices/command` `{deviceId,command:'play'|'pause'|'seek'|'volume'|'track'|'next'|'previous'|'transfer',trackId?,position?,volume?,queue?,fromDeviceId?}` -> `{ok}`. Requires target session owned by caller, explicit permission/unlock needed for autoplay. Can run server on LAN for LAN control without Internet. Native local discovery handled in Flutter.
- POST `/api/push/subscribe` `{subscription}` web-push; DELETE same. POST `/api/push/device` `{token,platform}` FCM if configured.
- GET `/api/admin/overview` -> `{counts,users,events,integrations,storage}` admin only. PATCH `/api/admin/users/:id` `{plan?,role?,blocked?}`. GET `/api/admin/mailbox` dev admin only -> `{messages}` (real locally queued mail). GET `/api/admin/audit` -> `{events}`.

## Socket.IO
Connect to same base URL; auth `{token?:nativeToken,deviceId,name,kind:'web'|'windows'|'android'|'ios'}`. Auth required. Session validated on every incoming command. Events with ack callback -> `{ok:true,...}|{error:{code,message}}`.
- client `device:state` State -> server broadcasts `devices:changed` to own user.
- server `device:command` command payload -> client applies and reports actual state. Transfer sends pause to source and snapshot play to target; source resumes if target reports failure.
- server `settings:changed` `{settings,revision}` after successful HTTP PATCH, only to the authenticated user's devices. Ignore older revisions and overlay unsent local changes before displaying the new snapshot.
- client `room:join` `{roomId}`; `room:leave` `{roomId}`; `room:command` `{roomId,command,trackId?,position?,volume?,queue?}` -> server authoritative ACL checks and broadcasts `room:state` `{roomId,state,serverTime}`.
- server `room:members` `{roomId,members}`, `room:message` `{roomId,message}`.
- server `notification` `{title,body,url}`.

Use monotonic revision guards and seek correction for room drift; never let a device echo remote commands indefinitely. HTTP routes control durable state; realtime authorization isn't inferred from socket room names.
