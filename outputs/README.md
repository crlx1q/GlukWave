# GlukWave 1.0.0+18

- GlukWave-Setup.exe — Windows, один установщик.
- GlukWave-android-debug.apk — Android24+, версия18 с прежним сертификатом.
- GlukWave-windows.zip — переносимая Windows-сборка; рядом есть распакованная GlukWave-windows.
- GlukWave-source.zip — исходники и собранный веб для обновления сервера.
- START.md / VERIFICATION.md — запуск, реальные проверки и ограничения.
- releases.json / SHA256SUMS.txt — выдача и контроль файлов.
- archive/releases/1.0.0+17 — предыдущая проверенная версия, исходники и история для отката.

Секреты, рабочая база, кеши, build-каталоги и архивные бинарники не включаются в source.zip. Хостинг и физические устройства не изменялись. Не копируй всю outputs на общий сервер: выбирай требуемую поставку.
