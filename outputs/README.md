# GlukWave 1.0.0+25

Windows: GlukWave-Setup.exe — установщик; GlukWave-windows.zip — переносная версия.
Android: GlukWave-android-debug.apk — обновление с прежним сертификатом.
Сервер/веб: GlukWave-source.zip. Подробности — docs/PARITY25.md.

Плавный ход полосы времени без дополнительных запросов, исправленное перекрытие перемотки обложкой, лайки с новых и сортировка фонотеки/плейлистов. Текст под обложкой раскрытого ПК-плеера, сильнее фокус текущих строк, исправленная глубина Flutter-обложки, блик от ориентации и ускоренная загрузка отдельно от воспроизведения. Сердце уведомления связано с текущим треком и любимыми; заголовок называет активную волну. Запасной экран ошибки старта не реагирует на посторонние ошибки.

Хеши — SHA256SUMS.txt, проверки — VERIFICATION.md. Точная24 — archive/releases/1.0.0+24. Хостинг и установленный клиент не менялись автоматически.
