# Готовые файлы GlukWave

В корне находятся только актуальные сборки, их проверки и запуск:

- `GlukWave-Setup.exe` — один установщик Windows.
- `GlukWave-android-debug.apk` — Android APK с прежним тестовым сертификатом.
- `GlukWave-windows.zip` — переносимая Windows-версия.
- `GlukWave-source.zip` — последний собранный архив исходников; версия и дата в `VERIFICATION.md`.
- `releases.json`, `SHA256SUMS.txt` — сведения о сборках и целостности.
- `START.md`, `Start-GlukWave.ps1`, `VERIFICATION.md` — запуск и результаты проверки.
- `GlukWave-windows/` — распакованный текущий Windows-клиент для запуска и упаковки.

Изменённые исходники в `apps/` могут быть новее этих готовых файлов. Сборка не считается обновлённой без новой проверки и изменения манифеста.

`archive/releases/` содержит предыдущий установочный комплект для отката и исторические отчёты. `archive/sources/` сохраняет уникальные старые архивы исходников. `archive/previews/` содержит старые скриншоты.

`organization.json` записывает прежнее и новое местоположение каждого файла, SHA-256, удалённые дубликаты и устаревшие сборки. Исторические отчёты сохраняют пути на момент их создания; новое расположение ищи в этом реестре.

Повторная уборка: `powershell -ExecutionPolicy Bypass -File scripts/organize-outputs.ps1` сначала показывает план. Ключ `-Apply` выполняет его после проверки актуальных файлов. Скрипт не удаляет уникальные исходники, данные `var/`, сертификаты или текущие релизы; из старых клиентов сохраняет одну предыдущую версию.
