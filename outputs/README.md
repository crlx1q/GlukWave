Windows: GlukWave-Setup.exe — обычный установщик; GlukWave-windows.zip — переносная версия.
Android: GlukWave-android-debug.apk — обновление с прежним сертификатом.

Первая установка 27 обычная; внутри неё уже работает ежедневная проверка следующих обновлений с загрузкой, проверкой SHA256 и системным установщиком. Обновления приложений требуют публикации серверного каталога сборок оператором.

Проверки — VERIFICATION.md; хеши — SHA256SUMS.txt. Точная 26 для отката: archive/releases/1.0.0+26. Хостинг и установленный клиент не менялись.
