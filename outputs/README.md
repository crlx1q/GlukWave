# GlukWave 1.0.0+22

- GlukWave-Setup.exe — Windows-установщик.
- GlukWave-windows.zip — переносимая Windows-сборка.
- GlukWave-android-debug.apk — Android24+, прежний сертификат.
- GlukWave-source.zip — исходники и собранный веб.
- START.md / VERIFICATION.md — запуск и подтверждённые проверки.
- archive/releases/1.0.0+21 — точная предыдущая версия для отката.

Обложка сверху, управление под ней на вебе, ПК и телефоне. Оборот содержит название один раз, исполнителя, отдельный альбом, источник и длительность. Сохранены геометрия из HTML владельца, символ, отражение, вращение и выдвижение диска. Подробности — docs/COVER22.md.

Публичный импорт, плейлисты и HLS-исправления21 сохранены. Хостинг и установленный клиент владельца автоматически не обновлялись. Секреты, база и рабочие кеши не входят в исходный архив.
