Windows: GlukWave-Setup.exe — установщик; GlukWave-windows.zip — переносная версия.
Android: GlukWave-android-debug.apk — обновление с прежним сертификатом.

Кеш главной, любимого и плейлистов показывается до сетевого ответа. Фоновое обновление и переподключение сохраняют активный трек и очередь. Следующие два трека готовятся заранее; устаревшая предзагрузка отменяется. Поиск показывает быстрые источники раньше медленных. Добавлены отдельные страницы исполнителей.

Собственный фон входа из круглых точек, компактный мини-плеер, предварительный просмотр при свайпе и плавное раскрытие, уведомления сверху, оседание строк текста по таймкоду и поиск по настройкам.

Хеши — SHA256SUMS.txt, проверки — VERIFICATION.md. Точные файлы версии 25 — archive/releases/1.0.0+25. Хостинг и установленный клиент автоматически не менялись.
