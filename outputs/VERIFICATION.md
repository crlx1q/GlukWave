# Проверка GlukWave 1.0.0+9 — 10 октября 2026

Добавлены официальный доступный SoundCloud HLS через собственный плеер/EQ, автономное доверенное управление Flutter по LAN, исправления нижнего веб-плеера, сезонные эффекты (по умолчанию выключены) и серверная консоль с ASCII-логотипом владельца/градиентом. Прежние улучшения Discord, текста и света сохранены. Проект ещё не завершён целиком: незакрытые задачи записаны в docs/ROADMAP.md.

- Сервер: полный окончательный прогон 80/80. Настоящие HTTP-проверки HLS-прокси: сессии/отзыв, истечение источника/обновление, CDN origin, ключи/варианты/сегменты, диапазон, атрибуция, отсутствие скачивания и default OFF сезонов. Внешний SoundCloud transport изолированный; ключи на хостинге по сообщению владельца настроены, но живой поток этой итерацией не подтверждён. Blob-worker HLS разрешён CSP.
- Веб: 26/26 тестов, TypeScript и окончательная production-сборка прошли. Собственный сгенерированный AAC реально декодирован через AudioElement; EQ доступен, iframe нет, настоящий скрытый tab перешёл к следующему потоку. Проверены темы, 320/390/768/1280/1440px, шесть языков при масштабе 125%, wheel/keyboard, все сезонные режимы/сохранение/выключение/reduced motion. После исправления мобильного переключателя отдельно прошли 24 сочетания ширины/масштаба/языка. Uncaught errors нет. Bundle: /assets/main-CR20a8dh.js. HLS загружается отдельным блоком; остаётся build warning крупных HLS/анимированных иконок.
- Flutter: полный прогон 204/204, analyzer: 0 замечаний. Дополнительные 6 проверки раскрытого плеера по языкам при 320px/125% прошли отдельно, число не складывается с полным прогоном. LAN использует реальные loopback WebSocket/шифрование; проверены сопряжение, nonce/sequence/replay/tamper, account isolation, лимит/отзыв/повторное соединение/вложенное управление, один выход, пауза/позиция/volume/next/repeat и rollback при отсутствии кеша. Физическое устройство этими тестами не подменяется.
- APK: 185483305 байт, SHA-256 `64c776180db9f96a0da1cbe210a177db0b2467d5ef947c8fc0fb1f056c73e3f6`, build9, minSDK24/target36. Прежний debug-сертификат сохранён, v2 подпись проверена. Manifest/kernel/118 исходников/шесть языков/11 шрифтов/лицензии/HTTPS и копия сверены. APK остаётся тестовой beta.
- Windows: один GlukWave-Setup.exe, 24368602 байт, SHA-256 `7e51b380af8a6b756e65ddd4cf174d4157d308da2faed366b4f2968bd7fa26d4`. Release x64, AOT/DLL/CRT/ZIP сверены; 98 входных файлов сборки совпали с замороженными исходниками. Настоящая установка и удаление в отдельной папке прошли, 75 файлов сверены; выключенные desktop/startup задачи соблюдены, Start Menu создан/удалён. Запущенное приложение владельца не закрывалось; интерактивные checkbox/tray не нажимались. Authenticode-подписи нет.
- HTTP-загрузка: действительные версии 1.0.0+9 и диапазоны206 проверены для APK/installer; полный Windows EXE скачан через локальный API и совпал по размеру/SHA-256. Это не публикация файлов на хостинге.
- Консоль: 4 проверки ширины/ANSI/NO_COLOR/capabilities/статуса/закрытия и измеренных логов прошли. Пример выводится настоящим изолированным сервером после health/404 запросов; счётчики настоящие, CPU стартового примера не является замером production-нагрузки. Нет polling timer/непрерывной перерисовки; production JSON сохранён.
- Ресурсы: 184 секунд, один socket/room, очередь 100, 91 фрагмент собственного AAC-in-TS через настоящий proxy с fixture upstream. После прогрева медиана CPU процесса 4.98% одного ядра, retained heap delta −0.22 MB, RSS delta 2.36 MB. Использовался explicit GC для retained-heap снимков. Это короткий локальный сценарий, не доказательство отсутствия всех утечек или ресурсоёмкости публичного сервера.
- Независимая оценка scoped UI: PASS, второй раунд отдельного агента той же модели. Снимки/поведение проверены независимо; живой SoundCloud, звук физических устройств и реальные LAN/firewall ею не подтверждаются.

Оба клиента собраны с https://wave.gluk.tech. Новый backend агентом туда не публиковался. Чтобы официальный SoundCloud HLS появился у опубликованных клиентов, сервер должен получить эту версию кода и рабочий OAuth приложения. Отдельные разрешённые файлы поддерживают локальный кеш/скачивание; официальный HLS имеет offline:false. Для ограниченных YouTube/Яндекс источников остаётся официальный вариант — произвольный MP3 всего каталога не реализован и не обещан.

Автономный LAN работает между сопряжёнными Flutter-клиентами без публичного сервера: зеркало/управление/один выход и уже кешированная музыка принимающего устройства. Автообнаружение, IPv6, обмен разрешёнными файлами, браузерный автономный LAN и физическая Windows↔Android проверка остаются. Также открыты live OAuth/импорт четырёх площадок, качество аудио по тарифам, полный production-профиль CPU/памяти, настоящие письма/push/платежи, release-подписи и iOS.
