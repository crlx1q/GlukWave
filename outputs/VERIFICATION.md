# GlukWave — фактические проверки 9 октября 2026

Версия **1.0.0+3**. Подробные результаты: `docs/verification/2026-10-08/evidence.json` и `docs/verification/2026-10-09/client-updates-proof.json`.

## Текущая проверка

- Сервер **39/39 PASS**, Flutter **87/87 PASS**, analyzer без замечаний, TypeScript/production build прошли. При первом полном серверном прогоне Windows задержал удаление SQLite-файла теста; ограниченный повтор удаления исправил очистку, повторный полный suite прошёл.
- В изолированном браузере без звука проверены сохранение громкости 0.05 после reload, сохранение mute 0, отдельный артист и его выбор, поиск по словам настоящего сохранённого LRC. Персональные тексты не раскрываются чужим аккаунтам.
- Расширенный LRCLIB: исправление служебных суффиксов, автор в названии, структурированный поиск, осторожный выбор по длительности и ordinary-text fallback. Настоящий LRCLIB-запрос ранее вернул 39 синхронизированных строк. Наличие lyrics.ovh не гарантирует текст для каждой песни.
- Вход/быстрый плеер/мини-режим проверены widget/method-channel тестами, темами/ширинами и свежей независимой оценкой оформления PASS. Физический трей и телефон не автоматизированы.
- PWA **glukwave-shell-v13-native-auth-search**: текущая веб-сборка, offline сайт/приложение/мини-плеер/приглашение. API/Socket.IO не кешируются; CAPTCHA-ссылки не сохраняются как обычная навигация.

## Сохранность и границы

Все 85 файлов прежнего набора ранее восстановлены с точным SHA-256. Неизменённые архивы восстановления и итерации диагностик сохранены отдельно; junction для сборки не используется. Актуальные исходники/веб-сборка/макеты/документация — `outputs/GlukWave-source.zip`; проверяются CRC, соответствие каждому исходнику и отсутствие .env/секретов/базы/кеша. Итоговые суммы — `outputs/SHA256SUMS.txt`.

На wave.gluk.tech работает предыдущий backend. Эта итерация не публиковалась: новый native CAPTCHA API, поиск/тексты доступны локально до обновления домена. Google на опубликованном сервере ещё не настроен. Сторонние OAuth, живая Cloudflare-проверка, SMTP, push, Discord, платежи и аппаратное воспроизведение требуют отдельной проверки. Windows DSP, прямой Яндекс-вход, фоновое воспроизведение внешних источников, социальные функции и iOS остаются открытыми. Это не подтверждение полной готовности всего проекта. Полный объём сохраняется в `docs/PROJECT-STATUS.md`.

Прежние оценки оформления v8/выравнивания были SKIPPED из-за ограничений среды; свежая оценка входа/компактных плееров этой итерации — PASS. Прежние данные облачной проверки Atlas/R2 и комнат/устройств сохранены в общем evidence с их датами, заново в этой итерации не заявляются.
