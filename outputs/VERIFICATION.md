# Проверки 1.0.0+27

Полные прогоны: сервер 138/138, web 104/104, Flutter 528/528. Анализатор без замечаний. Повторные/частичные запуски не складываются с итоговым числом. После нехватки RAM полный Flutter-прогон выполнялся с ограниченной параллельностью; критерии не ослаблялись.

Финальная веб-сборка: современный браузер и режим совместимости SystemJS/ES5, размеры 1440/768/375/320, настоящее декодирование WAV, текст и попадание курсором/касанием в полосу времени. Это не настоящий старый Samsung Tizen. Отдельный замер непрерывной полосы: 89 движущихся кадров при 8–9 обновлениях дискретных часов аудио.

Независимая оценка дизайна PASS (тот же доступный поставщик модели); поднятая очередь мышью/пальцем, отмена без команды, автоскролл 1376 px, редактор главной, 6 языков, личный токен→существующий выбор коллекций, скрытие рекомендаций/отмена. Обзор нашёл невидимую за modal карточку главной и потерю отмены жеста очереди вне списка; оба случая исправлены и проверены повторно. Настольный плеер 104 px, базовый мобильный 60 px (веб при удалённом воспроизведении — 84 px со строкой устройства), панель громкости на 320/390/768/1280 при тексте 125%, заголовок окна 44 px и правая панель без второго транспорта проверены виджетами/снимками.

Задержанный MPV open воспроизводит найденную гонку передачи на Windows: Play/Pause после начала открытия применяются после открытия/seek, отменённая загрузка не запускается поздно. Настоящий перенос и звук владельца ещё требуют проверки устройства.

Обновления проверены через локальный HTTP: интервал 24 часа, объединение запросов, манифест и SemVer/+build, проверка размера/хеша, отмена и удаление частичного файла, смена сервера и запуск проверенного файла через тестовую подстановку установщика. Реальные системные мосты собраны; ОС-установка не выполнялась. Личный импорт проверен зашифрованным хранилищем, правами, приватностью, общим импортом/повторами и taste; реальные токены владельца не использовались.

APK/Windows/installer/ZIP сверены с замороженными источниками, версиями, SHA256/CRC, шрифтами и media runtime. Android debug с прежним сертификатом, Windows без Authenticode; iOS не собирался. Хостинг и установленный клиент не менялись. Доказательства: docs/verification/2026-10-18/parity27/parity27-evidence.json.
