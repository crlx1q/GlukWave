# GlukWave 1.0.0+18

Windows: запусти **GlukWave-Setup.exe** — один установщик с выбором ярлыка и автозапуска. Android: **GlukWave-android-debug.apk**, прежний сертификат для обновления17. Сервер в клиентах: https://wave.gluk.tech.

В этой версии: четыре режима умной волны и отдельные настроения, продолжение поиска/плейлиста похожими треками, повтор и подготовка источников, устойчивые команды устройств, обновлённые обложка/EQ/цвет. В новом браузере нажми кнопку разрешения звука, если браузер её требует.

Сервер и веб обновляются отдельно: **GlukWave-source.zip** содержит проект с production web build. Обновляй сервер и новые клиенты вместе: поля waveMode/waveMood/sequence требуют версии18. Сохрани свой .env и рабочую базу; они не включены в архив. Развёртывание и общие сервисы — docs/SHARED-SERVER.md. Для SQLite явно указывается DB_DRIVER=sqlite; удаление Mongo URI само по себе не переносит данные.

Результаты — VERIFICATION.md; алгоритм — docs/SMART-WAVE.md; незавершённое — docs/ROADMAP.md. Бинарники17, исходники и прежние заметки для отката — archive/releases/1.0.0+17. Хостинг не обновлялся, база не переносилась. Большой Flutter-редизайн отложен владельцем. APK подписан debug-ключом, Windows Authenticode не имеет; iOS не собран.
