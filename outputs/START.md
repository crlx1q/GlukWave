# GlukWave — запуск и текущий результат

Проект: `C:\Users\alish\Documents\Codex\2026-10-06\glukwave-soundcloud-yandex-music-youtube-spotify`.

В `apps/web` находится веб-приложение, в `apps/server` — Node.js сервер, в `apps/native` — Flutter-клиент Windows/Android/iOS. Стиль взят из вашего `Gluk-Wave-v2.html`: кремовый фон, Manrope с Nunito для казахских символов, тёплые акценты и тёмный плавающий плеер. Новый `Gluk-Wave-v6-PC-fixed.html` уточняет три мобильные вкладки, мини-плеер над ними, раскрытие обложки и жесты. Исходные материалы в `Downloads\d` и новый HTML сохранены без изменения.

## Открыть веб

Нужен Node.js 24 или новее. Из корня проекта:

```powershell
npm install
npm run keys
npm run dev
```

Затем открыть сайт **http://127.0.0.1:5173/** или сразу музыку **http://127.0.0.1:5173/app/**. Альтернатива — `outputs/Start-GlukWave.ps1`. Сервер и окно запуска должны оставаться открытыми. Остановка — Ctrl+C. Старый адрес `/#home` продолжает открывать музыкальное приложение.

Попробуйте поиск `Forss`: публичные треки SoundCloud уже находятся и играют без API-ключа. Зарегистрируйте свой аккаунт, сохраняйте музыку и создавайте плейлисты. В медиатеку также можно загрузить свои аудиофайлы, включить автокеш, добавить LRC-текст и комментарий на определённой секунде. Новая личная библиотека пустая: импорт создаёт настоящие записи, фиктивной музыки в поставке нет.

«Настроить под себя» открывает отдельные палитры светлой, тёмной и AMOLED тем, HEX-цвета, скругление, скорость и отключение движения, компактный вид, мягкий свет вокруг обложки и три вида волны. Bloom получен официальным Originkit CLI и адаптирован под GlukWave: курсор/касание и измеренная громкость музыки меняют форму. На экране плеера есть винил/CD, наклон и плоская обложка; Gluk Lo-Fi содержит сцены, дождь, независимый звук атмосферы, часы и режим без лишних элементов. Все эти функции реализованы и в вебе, и во Flutter.

Оформление доступно до регистрации. В аккаунте оно синхронизируется между клиентами; offline-изменения сохраняются до отправки. Собственный LRC к внешнему треку сохраняется лично для вас. Настройки API и технические причины недоступности площадок находятся у владельца сервера/администратора; обычный пользователь ничего такого не вводит.

В разделе языка доступны английский, русский, казахский, украинский, немецкий и испанский. Словари встроены в веб/Flutter. Ручной выбор сохраняется; автоматический использует страну по IP, затем язык устройства и английский. При домашнем локальном запуске страна не определяется — это ожидаемо. На сайте-визитке тоже есть выбор языка, информация о возможностях и список проверенных доступных сборок.

Администратор: внесите свою почту в `ADMIN_EMAILS` в `.env` **перед регистрацией**, перезапустите сервер, затем зарегистрируйтесь. Общего административного пароля нет.

## Где хранятся данные

По умолчанию база SQLite — `var/glukwave.sqlite`, загруженные оригиналы — `var/media`. Пользовательский кеш находится в браузере/приложении на устройстве. Локальные письма разработки записываются в `var/mailbox`; для отправки на настоящую почту нужен SMTP. Без SMTP восстановление пароля показывает недоступность и не утверждает, что письмо было доставлено.

`DB_DRIVER=mongo` и `MONGODB_URI` переключают сервер на MongoDB Atlas. `MEDIA_STORAGE=r2` и параметры R2 переключают оригиналы на приватный бакет. В текущем рабочем проекте владелец уже настроил Atlas/R2: 8 октября проверены настоящие сохранение данных, конкурентные изменения, загрузка, поток, скачивание и удаление своего тестового файла в изолированной базе. В архиве остаются стандартные локальные настройки; приватный `.env` не переносится. Перенос существующих данных описан в `docs/SETUP.md`; смена параметра сама по себе не переносит файлы и базу.

`.env`, локальная база, пользовательские файлы и секретные ключи не входят в архив исходников. Сохраняйте `.env` отдельно: ключ шифрования нужен для подключённых аккаунтов.

## Телефон и Windows

Flutter-команды выполняются в `apps/native`; подробная инструкция в его `README.md`. Адрес сервера владелец задаёт при сборке через `--dart-define=GLUKWAVE_SERVER=...`. В тестовой сборке его можно изменить долгим нажатием на версию в настройках; основной экран входа сохраняет обычный пользовательский вид.

Для телефона в вашей сети: `HOST=0.0.0.0` на сервере, `LAN_DISCOVERY=true` при желании и адрес `http://IP-компьютера:4000` в debug-приложении. Для сканирования веб-QR также нужен доступный телефону веб-адрес: `APP_URL`, `ALLOWED_ORIGINS` и адрес Vite должны соответствовать сетевому IP. Приложение самостоятельно не меняет настройки Windows Firewall.

Без интернета совместное управление работает через доступный локальный сервер; сохранённые аудиофайлы играют с устройства. Для разных сетей нужен общий доступный интернет-сервер. Android release и iOS требуют HTTPS.

Текущая версия — **1.0.0+8, 10 октября 2026**. Оба клиента подключаются к **https://wave.gluk.tech**, домашний IP не требуется. Изменения backend этой итерации агентом на домен не публиковались.

**Android:** `GlukWave-android-debug.apk` — тестовая beta с прежней debug-подписью v2. Точные размер, SHA-256, проверка сертификата и исходников указаны в VERIFICATION.md. Физический телефон отдельно не проверен.

Автозапуск по умолчанию выключен; выбранный автозапуск оставляет приложение в трее. Штатное удаление включено. Результат проверки текущего установщика и SHA-256 — в VERIFICATION.md. Windows-пакет без Authenticode-подписи.

ZIP остаётся дополнительной portable-поставкой. Сохраняются отдельные APK/EXE/ZIP с номером версии. Запущенное приложение владельца не обновляется и не закрывается при подготовке этих файлов.

Вход/регистрация встроены во Flutter; сервер умеет отдельно проверять Cloudflare с возвратом в форму. Точная доступность новых серверных возможностей на домене зависит от версии, опубликованной владельцем: эта итерация агентом не развёртывалась. Локальные проверки не подменяют живой вход. Подробности — `docs/CLIENT-UPDATES.md` и `docs/PLAYER-AND-LYRICS.md`.

Для повторной Windows-сборки установлены Visual Studio Build Tools C++/ATL, Windows SDK и CMake. `scripts/build-windows.ps1` использует отдельную короткую копию проекта и отдельный кеш, чтобы не превышать ограничение MSVC. Итог проверки описан в `VERIFICATION.md`. iOS на этом Windows-ПК не собран; для него нужны macOS/Xcode и подпись.

## Подключения площадок

- **SoundCloud:** публичный серверный поиск, обложки и метаданные работают без ключей; например, попробуйте `Forss`. Официальный плеер тоже работает по публичной ссылке. OAuth-вход и импорт личной библиотеки требуют ключей разработчика.
- **Spotify / YouTube:** серверный поиск и OAuth-импорт плейлистов с реальными ключами разработчика. Прямые ссылки используют официальные плееры. Живые OAuth-сеансы с вашими аккаунтами ещё требуют проверки.
- **Яндекс Музыка:** импорт CSV/JSON со ссылками и официальный веб-плеер. Прямой вход и поиск в закрытой библиотеке Яндекса в этой версии не реализованы.
- **Google, Discord:** настоящие OAuth-маршруты; необходимо задать ID/secret приложений и callback-адреса.
- **Почта, CAPTCHA, push:** SMTP, Cloudflare Turnstile, VAPID и Firebase подключаются через конфигурацию. Ключи VAPID генерируются локально. FCM/APNs нуждаются в вашем Firebase-проекте и платформенной настройке.
- **Unbound:** настоящий Stripe Checkout/Portal и проверка подписи webhook. Без Stripe-ключей и recurring Price оплата отключена. Beta выдаётся администратором и даёт возможности Unbound.

Spotify и YouTube сохраняют ограничения своих официальных плееров. Источники не превращаются автоматически в скачиваемые файлы. Фоновое воспроизведение и offline проверяются с собственными загруженными аудиофайлами. Во Flutter источники без прямого аудио открываются через официальные внешние приложения/браузер.

Подробные параметры для владельца сервера, callback-адреса, настройки домена `wave.gluk.tech` и официальные источники — в `docs/SETUP.md`. Домен отвечает, но эта новая серверная версия туда не публиковалась. Указание авторства Originkit/Morphicons и лицензии — в `docs/THIRD-PARTY.md`.

Эта версия — работающая локальная основа проекта с настоящими данными. Полный исходный запрос ещё не завершён: остаются внешние аккаунты, аппаратные проверки и сборки всех платформ. Фактические результаты проверки перечислены в `VERIFICATION.md`.
