# Запуск 1.0.0+27

На Windows запусти GlukWave-Setup.exe либо распакуй GlukWave-windows.zip целиком и открой GlukWave/glukwave.exe. На Android установи GlukWave-android-debug.apk поверх прежней версии. Это первый обычный переход на 27; ежедневная проверка обновлений встроена уже в 27.

Сервер/веб: GlukWave-source.zip и README.md. Для личного переноса и каталога обновлений — docs/UPDATES-AND-TRANSFER.md. Источники, данные и конфигурацию хостинга оператор обновляет отдельно; в исходниках нет частных данных/ключей.

Кеш главной/фонотеки ускоряет открытие, аудио для гарантированного офлайна сохраняй через «Скачать». Метаданные плейлиста сами по себе не являются аудиофайлами. Лайки, плейлисты и вкус сохраняются в прежнем аккаунте.
