# Запуск 1.0.0+26

На Windows запусти GlukWave-Setup.exe либо распакуй GlukWave-windows.zip целиком и открой GlukWave/glukwave.exe. На Android установи GlukWave-android-debug.apk поверх прежней версии.

Для сервера и веба используй GlukWave-source.zip, README.md и существующие инструкции развёртывания. Данные, секреты и внешние референсные репозитории в архив не входят. Сохрани свои данные и конфигурацию отдельно перед переездом.

Кеш автоматически ускоряет повторное открытие. Для гарантированного прослушивания без интернета сохраняй треки через «Скачать»: метаданные плейлиста сами по себе не являются аудиофайлами.
