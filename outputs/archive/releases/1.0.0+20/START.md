# GlukWave 1.0.0+20

Windows: GlukWave-Setup.exe. Android: GlukWave-android-debug.apk, обновление предыдущей версии с тем же сертификатом. Адрес клиентов: https://wave.gluk.tech.

Для исправлений HLS, долгих переносов и импорта обнови также сервер/веб из GlukWave-source.zip. В архиве есть собранный веб. Сохрани свой .env, данные и настройки серверного процесса; они не входят в исходники. Хостинг в этой работе не менялся. Развёртывание — docs/SHARED-SERVER.md.

Подключённые источники открываются из медиатеки/источников: выбери коллекцию, песни и назначение импорта. Spotify ожидает точное совпадение callback в Dashboard, обычно https://wave.gluk.tech/api/integrations/spotify/callback; фактическое значение определяется конфигурацией сервера.

Сохранённые разрешённые файлы остаются доступны в разделе Сохранённое без сети. Внешние потоки не превращаются этим обновлением в доступные offline-файлы.

Изменения — docs/REFINEMENT20.md. Проверки — VERIFICATION.md. Откат — archive/releases/1.0.0+19. Физические устройства проверяет владелец; iOS не собран.
