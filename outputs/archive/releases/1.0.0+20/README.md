# GlukWave 1.0.0+20

- GlukWave-Setup.exe — единый Windows-установщик.
- GlukWave-android-debug.apk — Android24+, версия20 с прежним сертификатом.
- GlukWave-windows.zip — переносимая Windows-сборка.
- GlukWave-source.zip — полный проект, обновлённый сервер и собранный веб.
- START.md / VERIFICATION.md — запуск, результаты и ограничения.
- archive/releases/1.0.0+19 — точная предыдущая поставка для отката.

Звук Flutter, подтверждённый перенос Connect, подключённые коллекции Spotify/SoundCloud/YouTube, рекомендации из импортов/жанров/тегов, ранняя волна без запроса по кругу. Видимый активный аппарат, непрозрачный чехол, живой эквалайзер и исправленная длинная очередь. Подробности — docs/REFINEMENT20.md.

Хостинг не обновлялся. Для новых API нужен сервер из этой поставки. Секреты, рабочая база и кеши в исходники не включены.
