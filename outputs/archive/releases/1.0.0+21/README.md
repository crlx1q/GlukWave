# GlukWave 1.0.0+21

- GlukWave-Setup.exe — единый Windows-установщик21.
- GlukWave-android-debug.apk — Android24+, прежний сертификат.
- GlukWave-windows.zip — переносимая Windows-сборка.
- GlukWave-source.zip — полный проект, обновлённый сервер и собранный веб.
- START.md / VERIFICATION.md — запуск, проверки и ограничения.
- archive/releases/1.0.0+20 — точная предыдущая поставка для отката.

Новый Connect без второго плеера, компактный удалённый выход, аккуратная цикличная волна и двухстрочный веб-текст. Обложка из отдельного HTML владельца с фирменным символом и выдвижением диска. Windows runtime теперь действительно декодирует HLS; временные ошибки больше не пролистывают очередь, действующие ссылки восстанавливаются после потери серверного кеша. Подробности — docs/REFINEMENT21.md. Публичный импорт всех четырёх площадок по нику/ссылке работает через существующий выбор песен без OAuth/API-ключей; неполная выдача показана явно (docs/PUBLIC-IMPORT.md).

Лайки, создание и состав плейлистов меняются сразу с возвратом при ошибке. У песни видно, в каких плейлистах она сохранена. Добавлены поиск по своей библиотеке, редактирование описания/доступа, порядок песен и удаление с подтверждением. Сервер сохраняет одно изменение состава вместо повторной отправки всего списка.

Хостинг не обновлялся. Секреты, рабочая база и кеши в исходники не включены.
