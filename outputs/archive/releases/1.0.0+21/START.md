# GlukWave 1.0.0+21

Windows: GlukWave-Setup.exe. Android: GlukWave-android-debug.apk. Адрес клиентов: https://wave.gluk.tech. Для Windows замена старого клиента обязательна: прежняя DLL не поддерживает HLS.

Обнови также сервер и веб из GlukWave-source.zip для восстановления защищённых ссылок. Сохрани собственный .env, базу, данные и существующий TOKEN_ENCRYPTION_KEY; они не входят в поставку. Один и тот же ключ должен использоваться всеми процессами сервера. Хостинг в этой работе не менялся. Инструкции — docs/SHARED-SERVER.md.

При повторной ошибке Windows новый журнал: %APPDATA%/tech.gluk/glukwave/logs/glukwave.jsonl. Личные данные и параметры доступа очищаются; файл ограничен с одним предыдущим журналом. В +20 такого постоянного журнала не было.

Откат: archive/releases/1.0.0+20. Физические устройства проверяет владелец; iOS не собран. Сохранённые разрешённые файлы доступны без сети; внешние потоки не становятся этим обновлением offline-загрузками.
