# GlukWave 1.0.0+19

- GlukWave-Setup.exe — Windows, один установщик.
- GlukWave-android-debug.apk — Android24+, версия19 с прежним сертификатом.
- GlukWave-windows.zip — переносимая Windows-сборка; рядом есть распакованная GlukWave-windows.
- GlukWave-source.zip — исходники и существующий собранный веб.
- START.md / VERIFICATION.md — запуск, реальные проверки и ограничения.
- releases.json / SHA256SUMS.txt — версии и контроль файлов.
- archive/releases/1.0.0+18 — предыдущая проверенная поставка для отката.

В +19 переработаны нативные мобильный/Windows интерфейсы, полноэкранные слова, сохранённая музыка, вход сканированием с телефона и локальное энергосбережение. Сервер и веб в этой итерации не изменены. Секреты, рабочая база, кеши, build-каталоги и архивные бинарники не включаются в source.zip. Хостинг и физические устройства не изменялись.
