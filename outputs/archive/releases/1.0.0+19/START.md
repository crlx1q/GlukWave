# GlukWave 1.0.0+19

Windows: запусти **GlukWave-Setup.exe** — один установщик с выбором ярлыка и автозапуска. Android: **GlukWave-android-debug.apk**, прежний сертификат для обновления версии18. Сервер в клиентах: https://wave.gluk.tech.

В этой версии — фирменный Flutter-интерфейс для телефона и ПК, постоянный нижний плеер Windows, отдельный экран слов с компактной обложкой сверху и управлением снизу. Доступны темы, скругление, шрифты, масштаб, очередь, комнаты, Connect и существующие функции аккаунта.

Чтобы слушать без сети, заранее сохрани разрешённые треки или плейлист через меню, затем открой **Сохранённое**. Закреплённые загрузки отделены от временного кеша. Сохраняются аудио, метаданные, обложки и доступные слова. Выход из аккаунта удаляет приватные сохранения. Энергосбережение выбирается в настройках этого устройства.

На авторизованном телефоне вход на компьютере подтверждается через сканер или ручной код. Перед подтверждением показывается название запрашивающего устройства. Само сканирование вход не подтверждает; чужие серверные QR не принимаются.

**GlukWave-source.zip** содержит проект и ранее собранный веб. Для +19 обновление хостинга не выполнялось; нативные клиенты используют существующий API версии18. При ручном развёртывании сохрани свой .env и рабочую базу — они не включены в архив. Развёртывание — docs/SHARED-SERVER.md.

Результаты — VERIFICATION.md; изменения — docs/NATIVE-REDESIGN.md; незавершённые задачи — docs/ROADMAP.md. Предыдущая поставка18 сохранена в archive/releases/1.0.0+18. Физические устройства проверяет владелец. APK подписан прежним debug-ключом, Windows Authenticode не имеет; iOS не собран.
